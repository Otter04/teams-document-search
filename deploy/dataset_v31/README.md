## 검증 범위와 한계

파서·참조·전달 검증은 독립적인 정보추출 정확도 점수가 아니다. 신규 구형 Word 파일의 변환본은 일부 표처럼 보이는 내용을 연속 문단으로 전달한다. 원본을 textutil로 별도 읽어 공백을 제외한 문자 누락이 없는지 검사했으며, 임의로 열 경계를 추정해 만들지 않았다. 직접 구형 DOC를 PDF로 렌더링한 진단본은 한글 폰트가 빠져 검수/비전 입력으로 사용하지 않았다. 별도 변환본·원본은 모두 보존한다.

JSON/XML/JMX는 원문 줄이 기본 근거다. YAML 들여쓰기 경로는 탐색 보조이며 YAML 태그·설정은 실행하지 않는다. 원본에 반복된 긴 장비로그는 임의 삭제하지 않는다. 따라서 D-198의 26,000줄이 청크/임베딩 양 대부분을 차지한다.

첫 평가 점수를 본 뒤 검색 규칙이나 정답을 바꾸지 않는다. 정답표의 별도 원문 검수와 운영 성능 검증은 이번 개발 평가와 구분한다.
