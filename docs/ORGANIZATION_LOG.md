## 이전 문서 처리

이전 README와 NEXT_TASK는 [보관 폴더](archive/README.md)에 원본 바이트 그대로 복사한 뒤 루트 문서를 새로 편집했다. 완료된 과거 계획과 반복 상태 설명은 현재 안내에서 제거했으며, 이력 확인이 필요할 때 보관본을 읽는다. 보관본의 outputs 상대 링크도 바로가기로 연결했다.

이전 실험 보고서를 최신 선택에 맞춰 다시 쓰면 당시 평가 근거가 달라진다. 따라서 점수·정답·프롬프트·실험 보고서·응답은 보존하고, 현재 선택의 기준 문서를 별도로 두었다. 오래된 버전 코드도 현재 코드에서 불러오는 경우가 있으므로 이름만 보고 삭제하지 않았다.

## 물리 경로와 용량

`outputs`의 실제 실험 경로와 `work`의 의존성 경로는 유지했다. 동결 해시와 코드 참조가 연결되어 있어 전체를 이동하면 재현이 깨질 수 있기 때문이다. 목적별 폴더는 자료 복제 없이 기존 위치를 가리키는 바로가기다. 이번에는 저장 용량 축소나 캐시 삭제를 수행하지 않았다.

로컬 자격 증명은 열람 자료모음·문서 보관본·실험 파일 해시 목록에 포함하지 않았고 변경하지 않았다. API 호출·설정 변경·추가 모델 실행은 없었다.
