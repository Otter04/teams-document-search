# 자료모음

먼저 [모델 선정 결정](../MODEL_SELECTION.md)을 읽고 목적별 폴더를 선택한다. 각 폴더의 바로가기는 기존 `outputs` 자료를 가리키며 복제본이 아니다.

- [01_설계와기준](01_설계와기준/README.md): 파이프라인·공통 블록·원문 기준 메타데이터 정책. (3개)
- [02_데이터셋과평가준비](02_데이터셋과평가준비/README.md): 원본/정답 패키지 및 동결 평가 입력. 보강 준비 패키지는 후속 실행 완료 후에도 재현 입력으로 유지한다. (3개)
- [03_현재코드](03_현재코드/README.md): 현재 버전의 진입점. 이전 버전 코드를 내부 의존성으로 불러올 수 있다. (6개)
- [04_현재파싱과검색결과](04_현재파싱과검색결과/README.md): 각 범위의 최신 확인 결과. 서로 다른 분모와 평가 범위를 구분한다. (7개)
- [05_모델선정근거](05_모델선정근거/README.md): 선정에 사용한 실제 실험·원문 대조 기록. 당시 미확정 문구보다 현재 MODEL_SELECTION.md 결정이 우선한다. (5개)
- [06_설명과실제예시](06_설명과실제예시/README.md): 설명용 발췌·비교 자료. 평가 원본은 해당 실행 폴더에 별도 보존한다. (2개)
- [90_선행코드와이전실험](90_선행코드와이전실험/README.md): 이전 결과·실험 계획·선행 구현이다. 현재 코드가 의존할 수 있어 불필요하다고 일괄 삭제하지 않는다. 현재 사용 지시는 아니다. (31개)
- [91_배포시점ZIP](91_배포시점ZIP/README.md): 각 제작 시점의 배포 스냅샷. 최신 재평가 결과를 포함한다고 가정하지 않는다. (2개)

전체 실제 경로는 [폴더 안내](../FOLDER_GUIDE.md)를 참조한다.
