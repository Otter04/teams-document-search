# 남은 작업

최신 후속 확인: 사용자의 요청으로 기존 Q-001~Q-061에 대한 오프라인 평가를 수행했다. [결과](outputs/indexing-retrieval-eval-001/README.md). 최신 BM25의 전체 Hit@5·평균 Recall@5는 100%이며, 벡터 단독과 단순 결합은 더 낮은 항목이 있다. 아직 운영 검색 설계·서비스·답변 생성은 구현하지 않았다. 평가 결과에 맞춘 추가 튜닝은 하지 않았고 별도 요청을 기다린다.

2026-10-20 갱신. **모델 선정은 완료: Qwen3.6-35B-A3B.** [선정 근거](docs/MODEL_SELECTION.md)를 기준으로 진행한다. 이 문서는 작업 목록이며 자동 실행·유료 호출 예약이 아니다.

## 현재 범위 — 인덱싱만 진행

2026-10-20 사용자 정정: 전체 모델 비교 성적을 만드는 것이 목적이 아니다. **현재는 예비 110문서의 파싱·문서 보강·청킹·색인 준비에 한정한다. 검색 설계는 아직 하지 않았으므로 검색·답변 구현과 생성 요청은 진행하지 않는다.** 아래 과거 권장 작업 중 검색 연결은 이번 실행 지시가 아니다.

**후속 지시로 의미 보강·bge-m3 임베딩을 추가하여, 현재 110/110문서의 BM25·벡터 색인을 완료했다.** [최종 결과](outputs/indexing-110-semantic-vector-001/README.md). 기존 원문 1,072청크에 Orin Qwen3.6의 검수된 의미 보강 청크 17개를 추가했다. 제안서 13개·메모/메일 4개에 새 보강 호출 17건을 수행했으며, 외부 유료 API나 새 비전 호출은 없다. 1,089개 벡터의 파일 저장·재로드·문서 연결 검증을 마쳤다.

날짜 모호성 13건·이미지 자유 설명 103문장은 검수 대기로 유지한다. 이번에는 LLM이 핵심 구절을 선택한 발췌형 요약 17개를 채택했고, 자유 서술형 요약은 만들지 않았다. 검색·답변 설계 및 구현은 별도 사용자 요청 전까지 시작하지 않는다. 작성 도중이던 검색·답변 초안은 work에 보류했으며 실행하지 않았다.

비교용 실행기는 응답 45개를 보존하고 중단했다. Orin 모델 서버는 유지했다. 기존 OpenRouter의 검수·교정된 121장 재사용 결정과 메타데이터 우선 정책을 유지한다. 아래 과거 권장 작업은 현재 완료된 BM25 색인을 다시 시작하거나 중단한 모델 비교를 재개하라는 지시가 아니다.

아래 로컬 서빙·평가 설명은 이번 목적 정정 이전의 진행 기록이다. 전체 비교 작업은 재개하지 않는다.

## 로컬 서빙 후속 작업

Orin에서 기존 AWQ 모델을 메모리 80%·문맥 16,384로 구동했고 텍스트·이미지 기본 요청이 성공했다. [실행 결과](outputs/orin-serving-run-001/README.md). 이후 문맥 49,152 전체 평가용 서버가 자동 캐시 26.81GiB 할당 중 실패했다. 현재 캐시를 8GiB로 직접 제한하고 이미지 재사용 캐시를 껐으며, 가상 이미지 초기 점검 생략과 모델 파일 읽기 캐시 반환 후 첫 전체 평가 이미지가 성공했다. 전체 평가는 진행 중이며, 이 직접 지정이 80% 기반 자동 계산보다 우선한다. [현재 전체 평가 상태](outputs/orin-evaluation-run-001/README.md)를 기준으로 확인한다.

다음 연결 작업은 로컬 API를 기존 비전·보강 실행기에 연결하고, JSON 출력 옵션과 공통 블록 검증을 적용해 기존 자료로 회귀 평가하는 것이다. 기본 요청 성공은 전체 평가 통과를 의미하지 않는다. 새 결과는 과거 동결 평가와 분리해 저장한다.

## 다음 권장 작업: 선택 모델의 보강 입출력 설계 정리

1. 요약의 목적·내용 우선순위를 구체화하고 메타데이터 반복과 업무 핵심 요약의 역할을 구분한다.
2. 복합 요약 정답을 세부 사실로 나누는 등 프롬프트와 평가 기준을 맞춘다. 수치·조건·부정의 의미 오류는 계속 구분한다.
3. 근거의 block/source 연결, 상태·값·사유·후보 조합을 정리한다. 단순 표기 차이와 의미 오류를 구분한다.
4. 기존 규칙값과 충돌하거나 pending_vision/needs_review인 필드에 LLM 후보를 자동 확정하지 않는 병합 방식을 구체화한다. H-007 작성일의 잘못된 모의 병합을 검증 사례로 삼는다.

현재 수정 프롬프트는 대화에서 제안만 했으며 적용·재호출하지 않았다. 기존 동결 평가를 덮어쓰지 않고 변경이 필요하면 새 버전으로 기록한다. 먼저 저장 응답과 원문을 활용한 설계·오프라인 점검을 진행할 수 있다.
