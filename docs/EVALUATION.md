# 평가 기준과 재현

현재 데이터 규모와 단계별 성적은 [README](../README.md)의 표가 기준입니다. 원본 측정일은 2026-11-11이며 게시를 위해 모델을 다시 호출하지 않았습니다.

## 성공의 정의

질문에는 하나 이상의 필수 근거 묶음이 있습니다. 각 묶음에 등록된 대체 청크 중 하나 이상이 검색되어야 하고, 모든 필수 묶음이 상위 N개 안에 있어야 성공입니다. 근거 순위는 각 묶음의 최초 발견 순위 중 가장 뒤의 순위입니다. 한 묶음이라도 없으면 미발견입니다.

예: 두 근거가 각각 3위와 17위에서 발견되면 상위10 실패·상위20 성공입니다. 같은 문서의 다른 청크가 있다는 이유만으로 성공하지 않습니다.

## API 없는 재채점

```bash
python3 evaluation/replay.py
```

공개용 저장 순위와 정답 그룹으로 네 단계의 상위10/20/50·미발견을 다시 계산합니다. 저장된 성공 플래그를 그대로 읽지 않습니다. RRF 순서·점수, 리랭커 후보 집합 보존, 질문/청크 중복, 게시 파일 해시도 검증합니다. 모델 답변의 의미를 새로 검수하거나 새 검색을 실행하지 않습니다.

## 시간과 오류

중단 없이 끝난 78질문의 평균 전체 시간은 50.815초였습니다. 여기에도 API 요청·저장·일부 재시도가 포함됩니다. 4질문은 중단 후 이어 실행했으므로 중단 간격을 포함한 전체82 평균 78.976초를 일반적인 검색 지연으로 제시하지 않습니다. 문서 묶기·정답 채점은 검색 시간에 포함되지 않습니다. 동시 요청과 네트워크를 통제한 운영 부하 시험도 아닙니다.

Qwen 재작성은 82회 성공, 임베딩은 83시도 중 82성공, 리랭커는 98시도 중 82성공이었습니다. 실패 시도와 복구를 구분합니다. I074는 재작성에서 식별자 누락 검사를 통과하지 못해 원문으로 복귀했습니다.

## 한계

- 반복 사용한 개발 질문집입니다. 독립적인 실제 사용자 평가가 아닙니다.
- 추가 확인 대상 8질문도 순위 진단을 위해 실행했습니다. 서비스가 자동 응답에 성공했다는 뜻이 아닙니다.
- 최종 미발견: I004·I046·I049. 상위50 후보 밖 근거는 리랭커로 복구되지 않습니다.
- 요구사항 충족 판정·최종 문서5개·생성 답변의 성적과 구분합니다.
- 게시본은 원 API 응답 전부를 포함하지 않습니다. 순위 재채점은 가능하지만 API 점수 자체의 재검증은 로컬 보존 원응답이 필요합니다.
