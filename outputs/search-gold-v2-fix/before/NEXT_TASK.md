## 확장 평가 추가 완료

사용자가 제공한 99질문을 현재 검색 설정 그대로 실행했다. 새 간접 표현 30개에서 문서군 26/30, 지정 대표 문서 25/30. 기존 61개 순서 유지. [전체 결과](outputs/search-gold-v2-run-001/REPORT.md) · [현재 평가세트 포인터](datasets/search-evaluation-current.json). 검색 튜닝은 아직 하지 않았다.

새 실패는 Q-075 결합 상위 30청크 탈락, Q-081 두 분기 후보 누락, Q-082·Q-084 모호한 날짜 확인 요청, Q-099 첫 견적 대신 최신 견적 대표 선택이다. Q-082에는 재작년을 작년으로 부분 인식하는 별도 분석 오류도 있다. 새 필수 정답 전체 기준에서는 Q-061의 다중 정답 누락도 남아 있다. 다음 개선 시 원래 61개와 확장 99개 기준을 구분하고, 전체를 같은 정답으로 회귀 확인한다.

## 다음 우선순위: 질의 분석과 검색 품질 보완

1. **조건 평가의 의미 정리:** 원래 정답 필터와 실제 추출의 표현 차이(대상 시스템 추가, 최종본 선호)와 실제 누락을 분리한다. 원래 정답은 보존하며 새 기준은 검수·버전 관리한다. 엄격한 일치 20/43을 단순히 모두 잘못된 메타데이터라고 설명하지 않는다.
2. **날짜 역할:** ‘2025년 유지보수 계약’의 유효기간과 ‘문서일자 2025년’을 구분한다. Q-008은 2025년 계약이지만 D-016의 문서일자는 2024-12-22다.
3. **질의 분석 LLM:** 최종 평가에서 호출한 9질문 모두 2.5초 제한 초과 후 규칙으로 처리했다. 제한을 낮춰 응답 목표를 맞춘 것이 LLM 분석 성공은 아니다. 지연 원인과 실용적인 보조 범위를 먼저 확인한다.
4. **남은 2문항:** Q-043 `mall-db02`는 결합 상위 30청크에서 정답이 탈락, Q-053 ‘부가세 포함 공공기관 견적’은 두 분기의 50개 후보에 정답이 없다. 후보 확보와 문서 다양성을 먼저 진단한다.
5. **회귀·대표 버전:** 번호형이 이전 16/16 → 15/16으로 내려가 5%p 회귀 제한을 넘었다. 질문별 대표 버전의 검수 정답도 필요하다. 원래 최신본 라벨 기준 29/30은 잠정치다.

90% 문서 노출 목표는 넘었지만 **전체 검색 최종 합격은 아니다.** G1, 대표 버전 검수, 기존 대비 유형 회귀, 독립 검증이 남아 있다. 새 모델 리랭커나 별도 정확 번호 상단 고정 2a는 아직 채택하지 않았다.

## 이후 실제 서비스 연결

- 실제 SharePoint/Graph 수집, 변경분·삭제 동기화, 원본 URL, 사용자별 접근 권한.
- 실제 운영 자료와 독립 검수 정답, 동시 요청·장애 복구 시험.
- Teams 개인 탭 연결. 검색 결과별 새 설명이나 생성형 답변은 현재 설계에 포함하지 않는다.
- 첨부 검색 설계의 장비 기준은 Jetson AGX Orin 64GB다. Spark 전환은 보류 상태로 구분한다.

현재 API는 Orin `127.0.0.1:8020`, Mac 확인 화면은 인증된 SSH 터널을 통한 `127.0.0.1:18020`이다. VPN·SSH 연결이 끊기면 화면에 접근할 수 없다. 외부 공개 서비스가 아니다. 사용자 검색·클릭·피드백 기록은 저장하지 않는다.
