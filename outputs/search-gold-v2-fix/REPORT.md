## 변경 사항

- 질문의 일반 표현과 원문 용어(PDA·무선·TMS·migration/cutover)를 연결한다. 특정 정답 ID나 거래처를 추측해 고정하지 않았다.
- 결합 후보 최대100개를 모두 경쟁에 남긴다. 긴 문서의 약한 추가 청크가 점수를 부풀리지 않도록 보조 가산점 범위는 기존 상위30개로 유지했다.
- 재작년은 전전년으로 해석한다. 연도+계절은 연도만 우선하고 월 범위는 확정하지 않았음을 화면에 알린다.
- 첫 견적·처음 가격표는 같은 문서군에서 검색된 숫자 버전의 최솟값을 대표로 선택한다.
- 동작 검사29개 통과, Orin 배포 코드 해시 일치, 원본/검색 인덱스 각각110문서·1,089청크 유지.
