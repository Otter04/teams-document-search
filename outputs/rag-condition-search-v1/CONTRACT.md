# 명시된 문서 종류·대상 시스템 조건

2026-10-18. 이전 실행 rule-search-run-004의 색인·원문·사전·메타데이터·BM25 점수 식은 고정한다. 비교 기준일은 기존과 동일한 2026-10-17(Asia/Seoul)로 고정하고, 별도로 현재 날짜의 주요 질의도 확인한다.

- 문서 종류: 계약서/계약, 견적서/견적, 제안서/제안, 실행 로그/로그, 서버 구성도, 네트워크 구성도, 일반 구성도(두 종류의 합집합), 메일/메모(기타)를 명시한 경우만 사용한다. 겹친 표현은 가장 긴 표현을 우선한다. 서로 다른 종류가 동시에 언급되거나 부정·복수 선택·인용이 있으면 추정하지 않는다.
- 대상 시스템: 기존 인수인계서 기반 system_terms의 명칭을 경계가 일치할 때만 사용한다. MES와 MES2, TMS와 tms-db01은 구별한다. DB·DR을 특정 시스템으로 추정하지 않는다. 둘 이상의 시스템이 있으면 연동/선택/비교를 임의 해석하지 않고 시스템 필터를 보류한다.
- 기존 날짜·실행결과 조건에 새 필터를 AND로 더한다. 한 필드의 상충 조건은 오류로 반환한다. 보류·누락 메타데이터를 참으로 간주하지 않는다. 검색 후보를 제한한 뒤 모든 적격 청크를 기존 점수 식으로 계산한다. 필터 후 BM25 통계를 다시 계산하거나 상위 후보를 먼저 잘라내지 않는다.
- 조건이 불명확하면 검색어와 보류 사유를 남긴다. 필터 적용 결과가 비어도 몰래 완화하지 않는다. metadata_conditions_checked는 적용한 메타데이터의 일치 확인이며 conditions_verified=false는 질문 전체 의미 조건과 답변이 검증되지 않았다는 뜻이다.
- 기존, 종류만, 시스템만, 둘 다를 전체 61개와 네이티브 정답 60개에서 비교한다. Hit@5/MRR@10/문서 회수율, 유형별 지표, 모든 질문별 변화, 새 악화 사례를 공개한다. 원문 없는 스캔을 평가에서 임의 제외하지 않는다.
- 정답 문서 ID·정답 필터를 검색기에 주지 않는다. Q-020/Q-034는 확인 대상일 뿐 구현 분기나 가중치에 쓰지 않는다. 별도 합성 기능 회귀 검사는 실제 미공개 검색 평가로 부르지 않는다.
