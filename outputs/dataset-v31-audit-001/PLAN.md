# v3.1 확인 및 증분 인덱싱 계획 — 2026-10-24

사용자 요청에 따라 먼저 폴더를 확인하고 기존 방식의 인덱싱 계획을 정리했다. 이번 확인에서는 생성기·모델·색인 적재를 실행하지 않았다. 첨부 변경 설명은 참고 자료로 취급하고 실제 파일을 대조했다.

기존155개 원본의 v2 해시가 현재 저장 색인 출처 해시와 일치함을 확인했다. v3.1의140개는 그 원본과 바이트가 동일하다. 변경 PPTX10개는 슬라이드별 본문 텍스트가 동일하고 기존 포함 이미지 해시도 모두 새 파일 안에 남아 있다. 로고·배경 등 이미지가 추가됐다. PDF5개는 페이지별 기존 추출 글자가 모두 유지되며 바닥글 등이 추가됐다. 이 검사는 화면상 위치·연결 구조의 동일성까지 보장하는 검수가 아니므로, 새 파일의 근거 위치 재연결은 별도로 수행한다.

현재 파일시스템에서 기존155개 모두 수정 시각이 v2와 다르다. 내용이 같은140개도 경로·원본 식별·관측 수정시각을 새 수집 기록에 연결한다. 이 수정시각 변화가 실제 업무 내용 수정이라고 단정하지 않으며, 문서 작성일·표지일·버전과 분리한다.

## 신규40개의 처리 경로

- 기존 지원 계열20개: DOCX8, XLSX1, PDF6, PPTX4, RTF1.
- 구형 Office10개: DOC4, PPT3, XLS3. 실제 OLE 바이너리임을 확인했다. 확장자만 바꿔 처리하지 않는다. 설치된 LibreOffice 변환 경로의 동작을 확인하고 원본 보존·변환본 분리·표/슬라이드/근거 위치 검증을 연결한다.
- 구조화/텍스트 자료10개: YAML4, JSON2, XML1, HTML1, CSV1, JMX1. 현재 v2 라우터에 이 형식들의 분기가 없어 어댑터·공통 블록 스키마/위치 확장이 필요하다. 설정 파일을 실행하지 않고 키·계층·줄 위치를 보존한다. CSV는 셀/행·열, HTML은 보이는 본문·표를 추출하고 스크립트를 실행하지 않는다. JMX는 XML 구조로 읽는다.

신규 스캔 후보 D-180 `[발주서] 도담캐피탈 DR 장비 발주서_20250905(스캔).pdf`는1쪽이며 직접 추출 글자가0자로 확인됐다. 이 페이지는 비전 처리가 필요하다. 다른 PDF5개는 직접 텍스트가 있다. 신규 PPTX4개는총14슬라이드이고 장식 포함 이미지가 있으므로 원문 검수 뒤 실제 비전 대상만 분리한다. 구형 PPT3개까지 포함한 전체 비전 요청 수는 변환·장식 분류·이미지 중복 제거 뒤 확정한다. 원본 대조를 하기 전 모델 호출 수·완료 시간을 확정하지 않는다.

## 실행 순서

1. v2 원본/파싱/보강/벡터/검색 응답/정답을 동결 보존하고 v3.1 전용 출력·출처 해시 장부를 만든다.
2. 바이트 동일140개는 기존 공통 블록·검수 비전·보강을 재사용하되 새 수집 출처·관측 수정시각을 연결한다. 변경15개는 서식·바닥글·장식 이미지와 실제 본문을 분리하고 근거 위치를 다시 연결한다. 장식 로고/배경을 업무 정보나 새 비전 질문으로 무조건 취급하지 않는다.
3. 신규40개를 형식별로 파싱한다. 새 형식 어댑터에서 텍스트/표/계층/슬라이드·페이지·줄·셀 위치가 공통 JSON으로 전달되는지 먼저 확인한다.
4. 필요한 실제 스캔/사진/구성도만 기존 Orin Qwen3.6으로 처리한다. 같은 이미지 응답은 픽셀·입력 조건 일치 시 재사용한다. 원시 응답을 보존하고 누락·오독·표 구조·중복·위치를 검수한다. OCR 별도 파이프라인이나 외부 유료 API를 추가하지 않는다.
5. 규칙 메타데이터 추출 후 의미 보강이 필요한 문서/필드만 기존 Orin LLM으로 보강한다. 기존17개 보강/요약은 근거 연결이 유효한 범위에서 재사용한다. 전 문서에 요약을 새로 생성하지 않는다. ver0.5/0.6/0.7처럼 실제로 내용이 다른 버전과 동일 내용을 담은 DOC/DOCX를 구분한다.
6. 기존 규격으로 청킹하고 bge-m3를 사용한다. 모델 지문·전처리·입력 문자열이 같은 벡터만 재사용하며 신규/변경 입력만 임베딩한다. 파일 해시가 같다는 이유만으로 날짜/머리말이 바뀐 임베딩 입력까지 동일하다고 가정하지 않는다.
7. Elasticsearch + Nori/BM25 + 벡터 색인을 v003으로 별도 적재한다. 현재155문서 v002와110문서 v001을 보존한다. 문서/청크/근거/벡터 차원·개수 전수 대조 후 후보 검색에 연결한다.
8. 현재 search-1.6.1과 질문 분석 ON·2.5초를 기준으로150개 평가한다. 기존125개 회귀와 신규25개를 분리하고 필수 정답 상위5 포함·1위·추가 정답·불필요 결과·날짜 준수·시간을 확인한다. 기존 Q-068/069의 날짜 정책 충돌은 별도 유지한다. 새 질문에 노출된 이후 튜닝 평가는 독립 평가라고 부르지 않는다.

## 평가 정답 변화

기존125개의 질문 문장·필수 대표 정답은 모두 동일하다. Q-004에는 D-169 `청람_OT설비 IP 할당표.xls`가 추가 정답으로 들어갔다. Q-123에는 D-168 `케이블 선번장_v0.9.xls`가 다른 버전으로 추가됐다. 신규25개는 Q-126~Q-150이다. 모든 expected_cards의 참조 문서가 목록에 존재하며 색인 대상으로 표시돼 있다. 정답표 자체의 원문 근거 검수는 아직 수행하지 않았으므로 정답 정확성을 확정하지 않는다.

정답·golden_strings는 평가 전용으로 보존하며 파싱·보강·검색 요청에 답을 제공하지 않는다. generator 스크립트는 실행하지 않는다.
