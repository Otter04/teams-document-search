# 평가기 검증 기록

**당시 검증의 기록:** 이 문서의 미구현·미검증 항목은 아래 버전의 검증 시점 기준입니다. 후속 파싱 실험을 거쳐 현재는 비전 LLM으로 이미지의 의미와 구조를 추출하는 방향으로 변경했습니다. OCR 고려사항은 후속 설계에서 제외하며, [현재 방향과 다음 작업](../parsing-run-002/README.md#현재-설계-방향)을 따릅니다.

검증일: 2026-10-14. 대상: `evaluate.py` v1.0.0.

**이 기록은 평가 프로그램의 검증입니다. 실제 RAG 파이프라인 또는 모델 성능 평가가 아닙니다.**

## 의도적으로 넣은 사례

- 문장 중간 줄바꿈과 공백.
- 청크 여러 개에 걸쳐 나뉜 문자열, 문맥 머리말에만 존재하는 문자열.
- 파싱·청킹 결과 자체의 누락과 비어 있는 결과의 구분.
- 검색 순위 5·6·10·11위, 검색 결과 없음, 중복 문서, 평가 대상 밖 문서.
- 정답 N/A에 값을 채운 환각, 틀린 거래처, 채점 필드 누락.
- 금액의 쉼표·소수·0, 불가능한 날짜, 초가 있는 로그 시각.
- 사본 묶음 이름 변경, 서로 다른 묶음의 잘못된 병합, 양성 예측 쌍 0개.
- 일부 질문만 맞혔을 때 전체 통과 방지.
- `=1+1` 같은 모델 출력을 Excel 수식이 아닌 문자열로 저장.

통합 검증의 가상 검색 결과는 성공 57건/전체 61건이 되도록 구성했습니다. 검색 전체 점수와 유형별 점수가 다른 경우에도 각 판정을 구분합니다. 이 숫자는 실제 시스템의 검색 성능으로 사용하면 안 됩니다.

## 엑셀 계산 검증의 제한

Python 보고서의 주요 자동 지표 12개를 Artifact Tool 계산 결과와 대조했습니다. 10개는 일치했지만 전체 Hit@5와 MRR 2개는 미리보기 엔진의 0 처리 때문에 달랐습니다.

- 별도 최소 예제에서 A1=숫자 0일 때 `IF(A1="","blank","value")`가 `blank`를 반환하는 현상을 재현했습니다.
- 가상 검색 입력에는 순위 0 두 건이 있었고, 해당 엔진은 이를 전체 Hit@5·MRR 집계에서 제외했습니다.
- 평가기의 Python 계산은 두 건을 실패로 포함합니다. 손으로 정한 예상 순위와 결과가 일치합니다.
- 기존 평가 엑셀의 수식은 수정하지 않았으며 미리보기 엔진의 계산 캐시를 결과 파일에 저장하지 않았습니다.
- 결과 파일의 자동 재계산 설정과 수식 보존은 확인했습니다. **실제 Excel/LibreOffice 앱에서 열었을 때의 계산 결과는 미검증**입니다.

현재 확정적으로 확인한 평가값은 `report.json`, `report.md`, 실행기록의 값입니다. 엑셀 수식 화면을 사용할 때는 Excel/LibreOffice에서 재계산한 뒤 보고서와 대조해야 합니다.

## 이 검증 시점에 수행하지 않은 작업

실제 수집·파싱·OCR·청킹·메타데이터 추출·색인·검색의 구현이나 성능 평가는 수행하지 않았습니다. 제공 문서 전체의 실제 산출물 연결은 당시 검증 범위에 포함되지 않았습니다. OpenRouter 호출, DGX Spark 실행, 모델 선택도 이번 작업 범위에 포함되지 않습니다.
