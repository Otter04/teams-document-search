# 작업명·핵심 필드·로그 문맥 검색 실험

2026-10-18. 원본·기존 평가·정답·기존 조건 필터를 보존한다. 비교 기준일은 2026-10-17로 고정한다. 모델/API 호출 없음.

- 작업명/대상 시스템은 extracted 메타데이터와 인용 근거만 사용해 각 네이티브 로그 청크의 별도 문맥으로 연결한다. 원문 text에 설명을 덧쓰지 않는다. 정기점검 TXT도 문서종류가 실행 로그이면 같은 규칙을 적용한다.
- 핵심 필드는 작업명, 계약/견적/오류 번호, 제목/파일명, 시스템/거래처, 명시된 표의 역할·호스트명·IP 셀이다. 표 역할은 정확한 열 제목을 확인한 경우에만 사용한다. 출처는 블록/셀 위치 또는 파일명/기존 메타데이터 인용이다.
- BM25 문서 최고 점수에 필드별 일치 토큰의 IDF 합×필드 가중치를 더한다. 필드 토큰은 어절·식별자·개념만 사용하고 음절 bigram은 제외한다. 동일 필드 안의 토큰 반복은 한 번만 계산한다. 여러 청크를 가진 문서의 보너스를 반복 합산하지 않는다.
- 첫 실행 전 가중치: 작업명 4, 표의 역할 4, 식별번호/호스트/IP 3, 제목/헤딩 0.5, 시스템/거래처 0.25. 임의의 문서 ID별 가중치·정답별 분기는 없다.
- 추가 표현 규칙: 로그/작업 맥락의 ‘전환’과 CUTOVER, ‘자동으로 서버/인스턴스를 늘리다/확장하다’와 오토스케일(링)/autoscale을 연결한다. 구성/전환 전체를 무조건 특정 기술로 바꾸지 않는다. 이 표현 보완도 별도 효과로 공개한다.
- 기존, 가중치만, 문맥만, 가중치+문맥, 표현만, 전체를 비교한다. 표현 추가가 없는 두 기능만으로 목표가 달성됐는지 따로 공개한다.
- 지표: 기존 61질문의 Hit@1/5, MRR@10, 질문별 정답 회수율, 모든 정답을 상위 5개에 포함한 질문 수, 네이티브 범위, 신규 성공/실패. Q-020의 D-036 순위와 Q-032의 정답 3개 각각의 순위를 보고한다.
- 결과가 바뀌어도 질문 전체 조건을 확인했다고 말하지 않는다. 개발 세트를 보고 만든 규칙이며 독립 홀드아웃 평가가 아니다. 의미 근거와 최종 모델 선택은 별도이다.
