# 새 비전 자료 원본 대조 기록

2026-10-24. Orin 응답 40건과 원본 이미지를 대조했다. 같은 픽셀 4개는 승인된 동일 응답을 재사용하여 44개 이미지 단위를 반영했다. 검수자는 assistant이며 독립된 사람 검수 결과가 아니다. 원본 응답은 수정하지 않았다.

| 구분 | 건수 |
|---|---:|
| HTTP 200 / 정상 stop |40|
| 잘림 / HTTP 실패 |0|
| 원본 응답의 표 구조 오류 |3|
| 수정 없이 채택 |12|
| 원문 대조 수정본 사용 |28|

28건에는 오독뿐 아니라 UI/사진 분류, 중복 전사, 근거 좌표 및 관찰 설명 보정도 포함한다. 이 수를 모델 정보 정확도로 환산하지 않는다. 개별 수정 사항은 `vision-review/*.json`, 별도 수정본은 `vision-reviewed-wire/*.json`, 원본 응답은 `vision-responses/*/response.json`에 보존했다. `source-review-freeze.json`은 이 파일들의 해시를 기록한다.

표 구조 오류는 D-120 3쪽, D-122 1·2쪽에서 발견됐다. UI 메뉴와 키/값 입력란이 섞여 행 번호가 범위를 벗어났다. 원본 화면에 따라 필드 표를 재구성했다. 응답 잘림·HTTP 실패·파싱 불가 JSON을 허용하도록 검증기를 완화하지 않았다.

장비 이미지의 실제 반복 라벨은 보존했다. texts와 nodes에 같은 물체를 두 번 기록한 중복만 제거했다. LED 점등을 실제 운영 상태로 단정하지 않았다. D-143은 그림의 장비 전면 3개와 라벨의 서버 4대를 구분했다.

차트는 축·제목·표시 최댓값을 보존했다. 관찰 설명을 보정했지만 정밀 시계열 수치를 복원한 것은 아니다. 현재 검색 투영은 직접 전사·표·노드·연결선 위주이며 claims의 관찰/추론 문장은 검색 청크에 넣지 않는다.

추가 비전 모델 호출은 없었다. 이번 결과는 원본 대조 수정본을 포함한 인덱싱 결과이며, 모델 원본 응답만의 무수정 성능 평가가 아니다.
