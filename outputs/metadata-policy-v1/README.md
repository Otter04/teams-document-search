## 확정한 기준

- 문서일자: 본문에서 확인하는 대표 날짜. 파일 수정일과 분리한다. 표지일과 명시적 작성일은 별도 필드로 검색한다.
- 파일 최종 수정일: 파일시스템에서 관찰한 수정시각. 실제 작성·제출·승인 날짜로 해석하지 않는다.
- 대상시스템: 문서종류에 관계없이 명시적 대상 표기·제목·파일명·현재 메일 제목의 근거를 적용한다. 단순 본문의 연동 시스템 언급은 제외한다.
- 본문에 없는 초안 작성일: 미확정. 생성기 날짜 산술이나 수정일로 채우지 않는다.
- 미관찰·검토 대기·비전 대기와 N/A(해당 기준에서 적용 대상 아님)를 분리한다. `null` 라벨은 정답 미확정이며 정답으로 채점하지 않는다.

[24개 필드의 저장 위치·적용 범위](field-dictionary.json). 기존 20개 채점 필드와 채점 제외 사업명, 새 날짜 필드 3개를 포함한다.
