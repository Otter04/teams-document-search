2026-10-18. 기존 파서·보강·검색 코드는 변경하지 않았다. 새 합성 30문서·60질문에 대한 **사람 검수 전 정답 초안 기준의 평가**다. 실제 독립 평가 성적이나 운영 정확도로 해석하지 않는다. 데이터와 정답은 검색 실행 전에 고정했다.

이는 파서가 글자를 잃어버린 경우와 구분된다. 새 원본 문자열 529/529와 표·셀 301/301은 보존됐으며, 이후 보강 규칙이 값을 알아보지 못하거나 검색 조건이 후보를 잘못 제한한 것이다. H-Q043의 계약서 작성일은 실제 추출됐지만 **거래처 미추출** 때문에 검색에 나오지 않는다.

H-Q053은 이미 정렬한 후보를 limit 전에 잘못 자르는 문제와 다르다. `상위 3개`라는 반환 개수 표현이 내용 검색어로 남아, 정렬 이전의 후보 집합 자체가 줄어든 문제다.
