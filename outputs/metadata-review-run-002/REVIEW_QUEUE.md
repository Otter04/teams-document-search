# 원문과 대조한 판단 대상 29건

라벨은 평가용 기대값이다. 아래 16건 불일치와 13건 보류는 겹치지 않는 29개 문서다. 원문·정답을 수정하지 않았다. 추출값이 있는 16건은 원문을 뒷받침하는 값으로 유지하고, 13개 초안의 문서일자는 계속 null/needs_review다.

## 4. 다음에 확정할 판단

1. 문서일자는 원문 대표일로 유지하고 파일 최종 수정일을 별도로 다룬다. 남은 작업은 수정일 수집·검색 연결과 기존 정답의 날짜 기준 검토다.
2. 시스템명이 제목·파일명에 명확할 때 구성도·메일도 시스템 정답을 채울지. 제안: 현재 인수인계서 기준대로 채운다.
3. 본문에 없는 초안 작성일을 어떤 원천에서 얻을지, 본문 추출 평가에서는 보류를 어떻게 평가할지. 제안: 근거가 생길 때까지 보류하고 별도 라벨 버전을 검토한다.
