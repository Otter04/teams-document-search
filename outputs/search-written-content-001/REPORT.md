# 작성일 최신순·제안서 내부 구성도 검색 보완

2026-10-20 · 배포 버전 `search-1.1.0` · Orin 실제 검색 API와 화면 검증 완료.

## 요청한 질문의 결과

> 가장 최근에 작성된 네트워크 구성도가 포함된 문서를 찾아줘

이전 화면의 1위는 D-082 `HSR_network_diagram_rev2.pptx`(작성일 2025-02-17)였다. 질문이 문서종류 조건으로만 해석되고 날짜 정렬이 없었다. 변경 후에는 `written_date` 내림차순과 실제 구성도 포함 조건을 각각 적용한다.

| 순위 | 문서 | 명시적 작성일 |
|---|---|---|
| 1 | D-069 · DDC_네트워크구성도_검토본_스캔.pdf | 2025-08-27 |
| 2 | D-060 · 네트워크구성도_학사정보시스템_rev2.pptx | 2025-06-17 |
| 3 | D-025 · 네트워크구성도_WMS_rev1.pptx | 2025-04-26 |
| 4 | D-045 · 네트워크구성도_PACS_rev1.pptx | 2025-03-27 |
| 5 | D-091 · BHG_network_diagram_rev1.pptx | 2025-03-27 |

이는 **작성일이 확인된 일치 문서 중** 최신순이다. 내용 조건에 맞는 전체 23파일을 확인했다. 독립 구성도 10파일에는 작성일이 있고, 제안서 13파일에는 명시적 작성일이 없다. 제안서는 검색에서 빠뜨리지 않고 `undated_results`에 별도 표시한다. 화면은 날짜 확인 목록 최대 5문서군과 미확인 목록 최대 5문서군을 보여주며, 조건 일치 파일 수는 버전 묶기 전 수다.

예를 들어 D-098 제안서는 표지 날짜가 2025-09-15로 D-069보다 뒤지만, 이를 작성일이라고 바꾸지 않는다. 작성일이 없으므로 어느 문서가 실제로 가장 나중에 작성되었는지는 모든 23파일에 대해 단정할 수 없다. 작성일 미확인 목록은 최신순이 아니다.

## 제안서 내부 근거

`네트워크 구성도가 포함된 제안서를 찾아줘`로 검색하면 제안서가 반환된다. `청람정밀 네트워크 구성도가 포함된 제안서를 찾아줘`의 결과는 D-002 `㈜청람정밀_2025 MES 고도화 구축_제안서.pdf`다. 5페이지의 사용자/외부망, 보안·네트워크/FortiGate 200F, 애플리케이션·DB로 이어지는 기존 구성도 연결 정보를 사용한다. 같은 문서군의 PPTX도 연결된다.

- 문서 종류와 포함 내용을 분리했다. 단순 단어 등장이나 파일명만으로 포함 여부를 확정하지 않는다.
- 기존에 사실 색인으로 채택된 구성도 연결선과 연결 노드의 네트워크 표현이 있는 23파일만 대상이다. 미채택 원시 비전 구조나 설명 문장을 새로 사실로 승인하지 않는다.
- 포함 조건은 두 검색 분기에 동일하게 적용하고, 날짜 전체 조회에도 유지한다. 바깥 종류 ‘제안서’를 명시하면 그 조건도 필수다.
- 작성일 정렬은 일부 상위 후보 안에서만 수행하지 않는다. 전체 일치 청크를 페이지 조회하고 문서별로 묶은 후 순위를 정한다. 문서군의 기존 최신 버전 표시가 요청한 작성일 정렬을 덮어쓰지 않는다.
- 다른 날짜로의 대체는 없다. 화면에 작성일, 근거 위치, 날짜 미확인 상태를 구분해 표시한다.

## 기존 61질문 회귀 평가

기존 `repeat-005`와 동일한 B+R1·평가 기준일 2026-10-14·원본 정답을 사용했다. 정답은 검색 서버에 전달하지 않았고, 완료된 응답을 별도 채점했다.

| MRR@5 | 0.818306 | 0.818306 |

첫 실행 `written-content-006`도 동일 점수·문서 순서였으나 예시 검색 요청과 잠시 겹쳤다. 시간 비교는 다른 검색 요청과 겹치지 않은 `written-content-repeat-007`을 사용한다. 위 p95는 소수 개발 질문의 관측값이며 부하 시험은 아니다. 두 실행 모두 LLM 보조 9건은 제한시간 초과 후 규칙으로 처리했다.

기존 미해결 Q-043·Q-053은 그대로다. 90% 문서 노출 목표는 유지했지만, 전체 품질 기준·독립 검수·운영 준비 완료를 의미하지 않는다. 이번 신규 질문은 기존 61문항 점수에 추가하지 않았다.

## 확인 및 보존

- 단위/동작 검사 20개 통과: 날짜 역할, 전체 후보 정렬, 페이지 경계, 버전 대표 선택, 작성일 미확인 분리, 단어만 있는 자료와 미채택 구조 배제, 기존 검색 계약 포함.
- 실제 화면에서 질문 입력→작성일 최신순→D-069 1위 및 미확인 제안서 목록을 확인했다. 초기 화면 점검에서 발견한 문자열 연결 오류도 수정 후 재확인했다.
- 기존 61질문의 직접 인용 657개에서 원문 불일치 0, 위치 누락 0.
- 기존 인덱싱 산출물 해시 명세의 83파일과 평가 정답의 해시를 재확인했다. 원본 JSON·저장 응답·벡터·정답을 변경하지 않았다.
- Elasticsearch 기존/검색용 문서 110개·청크 1,089개 및 기존 별칭 유지. 색인 재생성이나 비전·보강 재호출 없음. 검색용 질문 임베딩과 기존 Orin 질의 분석 호출만 사용했다. 외부 유료 API 호출 없음.
- 포함 판정은 현재 채택 블록 기반의 보수적 규칙이며, 새로운 이미지 정답에 대한 독립 검증은 아니다. 기존 블록의 누락·오독은 이번 코드로 복구되지 않는다.
