## 변경 내용

1. 대표 버전: 같은 문서 번호의 후보끼리는 서명본·최종본을 초안보다 우선한다. 질문에 명시한 버전·상태·번호·날짜순·최초 버전은 유지한다. 파일명 끝 `(1)` 사본은 같은 문서군의 대응 파일명·버전·상태·수정시각이 같은 후보가 있을 때 원래 이름을 대표로 선택한다. 이 규칙은 파일 내용이나 바이트가 같다고 선언하는 규칙이 아니다. 명시한 번호가 다른 원래 이름으로 바뀌지 않는 방어 조건도 검증했다.
2. 문서 점수: 관련 청크의 최고 점수를 기준으로 한다. 약하게 관련된 청크가 많다는 이유로 가산점을 누적하지 않는다. 기존RRF 결합 및R1 코드 기반 조정은 유지하며 별도 모델 리랭커는 추가하지 않았다.
3. 표현 연결: ‘대표 주소→virtual-server/VIP’, ‘넘겨받기 시험→switchover/failover’, ‘접속해서 친 명령→PuTTY/SSH/show’, ‘재해 대비→DR’, ‘복제용→REPLICATION’, ‘회선 라벨→회선/WAN’, ‘랙 몇 번 칸→랙 위치/rack’ 등의 일반 표현을 연결했다. 문서 종류를 먼저 인식하고, 저장된 본문에서 각 개념군이 모두 확인되며 검증된 메타데이터 조건도 맞는 문서를 후보·우선순위에 반영한다. 정답 문서ID·질문ID·평가 정답 파일을 검색 규칙으로 넣지 않았다. 특정 거래처도 임의 추정하지 않는다.

본문에 근거가 확인된 문서 선호는 무조건적인 일치 보장이 아니다. 명시 날짜는 기존대로 두 검색 후보부터 필수 적용한다. 관련성이 낮은 결과의 혼입·정밀도는 별도 검수가 필요하다.
