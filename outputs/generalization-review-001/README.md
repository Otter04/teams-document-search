# 새 양식 추출·최신 수정순 검색 개선 결과

2026-10-19. **새 자료의 네이티브 검색 Hit@5는 33/47(70.21%) → 47/47(100%), 최신 수정순 정렬은 0/6 → 6/6으로 개선됐다. 기존 자료의 네이티브 60/60과 전체 60/61은 유지했다.** 유료 API·비전·임베딩 모델을 호출하지 않았다.

Hit@5는 상위 5개에 정답 문서가 하나 이상 있는 질문 비율이다. 정답 문서 회수율@5는 여러 정답 중 찾은 비율이다. 새 자료의 네이티브 질문은 두 지표 모두 100%이며 정답 첫 순위도 모두 1위다. 기존 질문 61개의 전체 반환 순위와 점수는 변경 전과 동일했다. 기존 Q-020·Q-032를 포함해 정답 순위 하락은 없다.

새 자료에서 기존 성공 질문이 실패로 바뀐 경우는 0건이다. 실패했던 내용 검색 14개와 정렬 6개, 총 20개 검사가 회복됐다. 질문별 실제 반환 ID는 [비교 파일](query-changes.json)에 보존했다.

전체 후보 48/48에는 **이미지 전용 스캔을 파일명·경로·메타데이터로 찾은 질문 1개**가 포함된다. 그 문서의 이미지 본문은 해석하지 않았으므로 비전 이해 성공으로 세지 않는다. 90% 목표 달성 판정은 이 질문을 제외한 네이티브 47개를 기준으로 한다.

## 무엇을 고쳤는가

| 문제 | 변경한 규칙 | 실제 개선 |
|---|---|---|
| 거래처 누락 | `Shared Documents` 위치 의존을 없애고 상위 폴더의 거래처 사전 이름·별칭과 정확히 대조. `거래처/발주처/Client/Customer` 라벨 지원. 경로와 본문이 충돌하면 검토 대기 | 0/30 → 30/30. 거래처 조건 때문에 비던 날짜 검색 후보 복원 |
| 메모·메일 종류 누락 | TXT의 제목 또는 파일명에 명시된 메모·메일 표현 인식. 본문 속 단순 언급은 사용하지 않음 | 문서종류 25/30 → 30/30. H-Q021~025 회복 |
| 로그 작업·시간·최종 결과 누락 | `작업명`, `작업 시작`, `작업 종료 result=...`와 오류 문맥의 `code=...` 지원. 중간 경고·체크포인트와 최종 결과 구분 | 작업명·시작·종료·결과 각각 0/5 → 5/5. H-Q027 회복 |
| 단독 표지 날짜 누락 | 제안서 첫 페이지·슬라이드의 독립 날짜 줄을 표지일로 인식. 명시적 작성일과 분리. 복수 날짜 충돌은 검토 대기 | 표지일 0/7 → 7/7. 작성일 15/15 유지 |
| 번호·표 필드 양식 의존 | 명시적 번호 라벨 뒤 영숫자 구분 형식 지원. 두 셀의 라벨·값 행에서 대표 금액·통화·VAT 추출 | 계약·견적 번호 각각 0/5 → 5/5. 금액·통화·VAT 각각 12/17 → 17/17 |

파일 수정시각은 이미 수집되어 있었다. 이번 문제는 수정시각 자체의 누락이 아니라 **거래처 추출 누락과 잘못 남은 내용 조건**에 있었다. 수집된 수정시각을 바꾸지 않았다.

| 3 | H-010 · 온라인몰 재고예약 제안서 | 2026-10-17 15:00 |
