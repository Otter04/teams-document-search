# 네이티브 파싱 재실행 결과

실행일: 2026-10-16 · 파서 2.0.0 · 공통 블록 규격 1.0.0

**후속 진행:** 사용자 선택에 따라 OpenRouter 비전 시험을 보류하고, [유료 API 없는 규칙 기반 문서 보강](../enrichment-run-001/README.md)을 구현·평가했습니다. 아래 내용은 이 파싱 실행 시점의 기록입니다.

**예비 데이터셋 110문서를 원본부터 다시 읽어 새 공통 블록으로 변환하고 평가했습니다. 네이티브 범위의 원문 보존·표본 셀 검사는 통과했으며, 전체 파싱은 비전 처리 대기 때문에 미완료입니다.** 사용자 선택대로 이번 실행에서는 모델을 호출하지 않았고, 다음 시험 서비스는 OpenRouter입니다.

## 실제 측정

| 항목 | 결과 | 해석 |
|---|---:|---|
| 입력 문서·원본 해시 일치 | 110/110 | 모든 입력 유지, 원본 변경 없음 |
| 공통 블록 스키마·참조 검사 | 110/110 | ID·부모·근거·좌표·표 셀 격자 일관성 |
| 네이티브 처리 단위 완료 | 231/231 | 원본의 문서·페이지·슬라이드·시트 목록과 별도 대조 |
| 네이티브 글자가 나온 문서 | 107/110 | 스캔 PDF 3문서는 글자를 생성하지 않고 대기 |
| 비스캔 필수 문자열 | **334/334, 100%** | 이번 네이티브 처리 범위 |
| 전체 필수 문자열 | **334/346, 96.53%** | 스캔의 12항목을 분모에서 제외하지 않은 결과 |
| 네이티브 표 검증 표본 | **531/531셀, 100%** | 24개 표/시트 영역. 추가 비어 있지 않은 셀 0 |
| 인코딩 대체 문자 문서 | 0 | 엄격한 디코딩, 파싱 예외도 0 |
| 생성 블록 | 5,267개 | 컨테이너와 실제 내용을 포함한 총수 |
| 원본 페이지·슬라이드 이미지 | 158장 | PDF 73쪽, PPTX 85장 |
| 비전 검토 대기 | **30문서의 121개 단위** | 넓게 잡은 후보 목록. 모두 실제 API 호출 필요가 확정된 것은 아님 |

DOCX 56/56, PPTX 72/72, XLSX 69/69, TXT 16/16, LOG 57/57의 필수 문자열을 보존했습니다. PDF는 64/76이며 빠진 12항목은 D-044·D-069·D-102 스캔 자료에 속합니다. 스캔본의 표·의미·연결 관계도 아직 평가하지 않았습니다.

표 표본은 DOCX 6개, XLSX 8개, PPTX 6개, 텍스트 PDF 4개 영역입니다. 네이티브 자료는 원본 OOXML을 별도로 읽어 비교했고, PDF는 이전에 원본과 대조해 만든 표 전사 자료를 재사용했습니다. 이 표본의 100%는 전체 자료의 표 분할·헤더 의미·읽기 순서가 모두 검증됐다는 뜻은 아닙니다. PDF 주석의 독립 사용자 검수는 아직 없습니다.

## 수정과 확인

새 파서는 표 컨테이너와 행·셀, 병합 범위, 원문 위치와 근거를 보존합니다. 제목·문단의 문맥을 연결하고, 원문과 모델 설명이 섞이지 않도록 저장 경계를 나눴습니다. LOG의 ERROR와 밀리초 시각도 실제 원문에서 추출합니다.

첫 실행에서 슬라이드 PDF의 배경 테두리 5개가 표로 감지되는 문제를 확인했습니다. 페이지 밖의 극소 셀을 가진 후보를 제외하고 해당 글자를 본문으로 읽도록 수정한 뒤 전체를 다시 실행했습니다. 가짜 정답이나 이전 이미지 인식 결과를 새 결과에 채우지 않았습니다.

13개 회귀 테스트가 통과했습니다. 실제 예비 세트의 병합은 단순한 범위이며, 복잡한 가로·세로 병합과 수식 캐시 누락은 합성 테스트로 구분해 검사했습니다. [파서 구현과 재현 방법](../rag-parser-v3/README.md)을 참고하세요.

PPTX 한글 렌더링 누락도 수정했습니다. 원본을 변경하지 않고 임시 렌더링 복사본에 Arial Unicode MS를 적용했으며, 85슬라이드 모두 원문 한글 문자 누락 검사에서 0건을 확인했습니다. 대표 구성도 이미지는 직접 확인했습니다. 글꼴 대체 때문에 원본 PowerPoint의 글자 폭·줄바꿈과 완전히 동일한 화면이라고 보장하지는 않습니다.

## OpenRouter로 이어갈 자료

대기 목록은 PPTX 85슬라이드, 이미지가 있는 텍스트 PDF 30쪽, 표 밖 그래픽이 있는 PDF 1쪽, 스캔 5쪽입니다. PPTX 표지·본문과 PDF 배경 이미지도 들어 있으므로 API 호출 전에 대상 범위를 다듬을 수 있습니다. 다만 미디어 파일이 없다는 이유로 도형 구성도를 제외하면 안 됩니다.

첫 모델 비교에는 **대표 7장**을 준비했습니다. 스캔 5쪽에 도형 구성도 D-007 1장, 텍스트 PDF 표 D-022 1쪽을 더했습니다. 이는 모델·프롬프트를 조정할 개발용 시험이며, 전체 세트나 독립 자료의 최종 검증을 대신하지 않습니다.
