# 독립 평가 준비 v1

현재 상태: **입력 규격·누출 방지 검사·평가 실행기 준비. 독립 평가 성적은 아직 없음.** 이번 개발 자료의 110문서·61질문과 날짜 확장 20검사는 독립 세트로 재사용하지 않는다.

## 수집할 자료와 평가 기준

- 새 원본 최소 30문서와 새 질문 최소 60개. DOCX/PPTX/XLSX/PDF/TXT/LOG를 고르게 포함하고 기존 문서의 변환본·복사본·개정본을 제외한다. 각 형식 3문서 이상을 권장한다.
- 문서군을 나누어 개발 자료의 같은 사업·문서 계열이 양쪽에 들어가지 않도록 검수한다. 단순 새 파일명·문서 ID는 독립성 증거가 아니다.
- 질문은 일반 검색, 날짜 역할, 수정일 정렬, 확인 가능한 정답 없음, 모호한 조건을 포함한다. 권장 비중은 일반 검색 30, 날짜/정렬 20, 정답 없음/모호함 10이다.
- 원문을 확인한 사람이 문서·질문·필드 정답과 근거 위치를 기록하고 검수자 식별자를 남긴다. 실행 결과를 보고 정답을 맞춰 쓰지 않는다.
- 파이프라인과 평가 기준을 동결한 뒤 실행한다. 수정하면 별도 버전으로 전체 회귀 평가한다. 모델·유료 API는 사용하지 않는다.
- 통과 목표: 네이티브 정답이 있는 검색 Hit@5 ≥90%, 지원하는 날짜 조건 위반 0, 최신 수정순 검사 전부 통과, 표지일을 작성일로 오인한 결과 0. 메타데이터 채운 값 일치율 ≥95%와 회수율·미확정 수를 함께 보고한다.
- 스캔·이미지의 본문은 비전 미처리로 따로 집계한다. 파일 수정시각만 확인 가능하더라도 시각 내용의 검색 성공으로 세지 않는다.

## 입력 파일

`templates/`의 JSONL은 빈 양식이다. 빈 입력은 통과하거나 100%로 계산되지 않는다. [필드 안내와 예시](PACKAGE_FORMAT.md)에 맞춰 새 폴더에 입력한다.

| 파일 | 내용 |
|---|---|
| manifest.jsonl | doc_id, 원본 해시, 문서군 키, 새 수집 출처, 검수자 |
| queries.jsonl | 질문 ID·자연어 질문·분류·출력 개수. 정답 없음 |
| answers.jsonl | 질문별 정답 문서·정렬 순서·근거·검수자 |
| metadata-labels.jsonl | 문서별 23개 평가 필드의 값/적용 제외/미관찰/미확정과 근거 |
| settings.json | 상대 날짜 해석 기준일 |

## 실행 순서

1. 새 원본을 기존 공통 블록 파서로 파싱한다. [파서 실행 방법](../rag-parser-v3/README.md)을 따른다.
2. 거래처·시스템 사전은 원문 운영 정보로 제공하고 정답을 보고 추가하지 않는다. 새 입력 사전의 해시도 기록한다.
3. [build.py](../rag-date-search-v1/build.py)에 새 parsed.jsonl, files-root, reference, rules, output을 지정해 수정일 수집·보강·색인을 만든다. 원본 gold는 입력하지 않는다.
4. 아래 실행기로 입력 검사를 먼저 하고, 통과한 같은 자료를 새 출력 폴더에 평가한다.

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=work/schema-deps \
  /Users/kangdongkyoon/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  outputs/independent-evaluation-prep-v1/holdout.py \
  --package /path/to/new-reviewed-labels \
  --run /path/to/new-built-run \
  --output /path/to/new-admission-output --validate-only
```

실제 평가는 `--validate-only`를 빼고 새 output 경로를 사용한다. 검사는 문서/질문 최소 수, ID·해시·정답 참조, 원문 근거·검수자, 개발 원본/문서군 중복, 코드 동결을 확인한다. 의미상 유사한 변형 문서를 전부 자동 탐지하지는 못하므로 문서군 독립성은 별도 검수도 필요하다.

`holdout.py`는 전달된 새 자료에만 실행한다. 이번에는 준비 검사에 합성 소형 입력을 사용했으며 이를 독립 성적으로 보고하지 않는다. 새 자료가 아직 없으므로 실제 독립 평가는 진행하지 않았다.
