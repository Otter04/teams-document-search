# 명확한 기간 필수화

사용자 요청: 명확한 날짜는 필수 조건. 0건일 때 날짜 자동 완화 금지. Q-061은2026년 백업로그3개만. 동일99질문 재평가 및 기간 밖 혼입 검사.

- 양 분기에 같은 날짜·추출확정 필터. 날짜가 지정된 문서종류도 보존하며 종류를 풀어 다른 종류로 대체하지 않는다.
- 연도+계절은 확실한 연도를 필수로, 계절 월은 미확정 안내.
- 명시 로그 종류+기간+작업 개념은 추출 job_name에 근거해 필수로 한다. DB_SNAPSHOT도 DB 백업의 한 형태로 지원한다.
- 유지보수 적용 연도는 원문 계약 시작·종료의 기간 겹침으로 해석한다. 작성/체결/표지/수정 날짜가 명시되면 해당 역할을 우선한다.
- Q-068·069의 기존 정답은 날짜 완화를 전제하므로 원본보존 채점과 정책준수(빈결과) 검사를 분리한다.
- 날짜미확인 및 기간밖 카드·다른버전 링크는 출력에서 제외. 기존색인·원본·정답·벡터 유지.
