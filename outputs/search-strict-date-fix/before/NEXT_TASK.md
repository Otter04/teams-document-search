## 남은 검색 품질 작업

1. 계약 유효기간과 문서일자 구분: Q-008의 2025년 계약 문서일자는2024-12-22다. 정답 노출 성공이 모든 날짜 역할을 정확히 해석했다는 뜻은 아니다.
2. 조건부 Qwen 질의 분석: 이번99개 중19번 호출 시도가 모두 시간 초과 뒤 규칙으로 처리됐다. LLM 분석 성공과 검색 성공을 구분한다.
3. 원래 필터 정답과 추출 표현 차이 검수, 독립 자료·순위 품질·동시 요청 등 운영 성능 확인. 99개는 개선에 사용한 개발 질문이다.
4. 현재 결과는 상위5에 필수 정답이 모두 포함되는 기준이다. 불필요한 결과의 혼입, 1위 정확도와 검색 정밀도는 별도로 검수할 수 있다.

날짜 기준은 운영KST 오늘/평가2026-10-14이며 작성일·표지일·수정일은 분리한다. 계절 정책은 명시 연도만 우선하고 월은 확정하지 않는다. 로그 실행기간은 log_start, 작업 개념은 추출 job_name으로 검증한다. [상세 설계](docs/SEARCH_DESIGN.md). 모델 리랭커는 추가하지 않았다.

## 이후 실제 서비스 연결

- 실제 SharePoint/Graph 수집, 변경분·삭제 동기화, 원본 URL, 사용자별 접근 권한.
- 실제 운영 자료와 독립 검수 정답, 동시 요청·장애 복구 시험.

- 첨부 검색 설계의 장비 기준은 Jetson AGX Orin 64GB다. Spark 전환은 보류 상태로 구분한다.

현재 API는 Orin `127.0.0.1:8020`, Mac 확인 화면은 인증된 SSH 터널을 통한 `127.0.0.1:18020`이다. VPN·SSH 연결이 끊기면 화면에 접근할 수 없다. 외부 공개 서비스가 아니다. 사용자 검색·클릭·피드백 기록은 저장하지 않는다.
