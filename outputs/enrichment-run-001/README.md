## 비어 있는 값의 의미

| 상태 | 채점 대상 필드 수 | 처리 |

| not_applicable | 1,072 | 해당 문서종류의 메타데이터 필드 적용 대상이 아님. 예: 계약서의 로그 종료 시각 |

비전 대기 75필드는 이미지에 값이 반드시 존재한다는 뜻이 아닙니다. 기존 시각 검토 후보인 **30문서·121단위**를 그대로 연결했으며, 표지·장식 이미지 등도 포함된 넓은 후보 목록입니다. 후속 실제 호출 장수와 같지 않습니다. 정답에 실제 값이 있는데 보류한 55항목은 비전 대기 18개, 초안 날짜 13개, 명시적 유형 라벨이 없는 계약유형 24개입니다. 이 외 정답과 다른 값 5개까지 합쳐 정답 값 60개를 아직 회수하지 못했습니다.

## 정답과 원문이 다른 16건

현재 점수는 원본 정답을 그대로 사용했습니다. 불일치 16건 모두 인용을 실제 원본 PDF·PPTX 또는 파일명과 다시 대조했습니다.

- 날짜 5건: 예를 들어 D-002 표지에는 **2025. 01. 13.**이 인쇄되어 있지만 정답 문서일자는 **2025-01-14**입니다. 표지 이미지도 확인했습니다.
- 대상시스템 11건: 예를 들어 D-007 제목·파일명에는 **MES**가 있지만 정답 대상시스템은 **N/A**입니다.

원문은 추출값을 뒷받침하지만, 정답 또는 필드 정의를 독립 검수자가 확인할 필요가 있습니다. 임의로 정답을 고치거나 이 사례를 채점에서 제외하지 않았습니다. **98.18%를 ‘원문 기준 실제 정확도 100%’로 바꿔 주장하지 않습니다.** [정답 검토 목록](evaluation/LABEL_REVIEW.md)과 [직접 원본 대조 기록](evaluation/label-review.json)을 참고하세요.
