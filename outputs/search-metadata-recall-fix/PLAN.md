# 검증된 메타데이터 기반 후보·우선순위 보완

기준: search-1.3.1, 최종99개 run-003. 정답·원문·색인·벡터는 수정하지 않는다.

1. 문서종류와 구체적인 VAT/통화/실행결과가 함께 있거나, 로그 실행기간과 작업 개념이 함께 있는 질문에 검증된 메타데이터 보조 경로를 연다.
2. 모든 인식된 조건이 extracted 상태로 일치하는 문서를 BM25의 OR 후보 경로로 넣는다. 기존 본문 검색·벡터 검색·거래처 강제 조건을 유지한다.
3. 작업 개념은 추출된 job_name에서 확인한다. 본문의 일회성 백업 언급이나 파일수정일로 백업 실행·실행연도를 추정하지 않는다.
4. 조건을 함께 충족한 문서를 우선하고 다른 후보도 유지한다. 추정 거래처·공공기관 분류·정답 문서 ID 규칙을 넣지 않는다. 모호한 계절은 실행기간 확정 우선순위에서 제외한다.
5. 대표 버전은 실제 표시되는 버전의 조건 충족 여부로 판단한다. 다른 버전의 조건을 잘못 물려주지 않는다.
6. 99개 전체 실제 API 평가와 33개 동작 검사를 진행한다. 마지막 날짜 23:59까지 포함하는 경계 검사도 포함한다.
