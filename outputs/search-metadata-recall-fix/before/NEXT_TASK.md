## 남은 검색 품질 작업

1. Q-053 공공기관·VAT 포함 견적은 두 분기 후보에 정답 D-100이 없다.
2. Q-061 올해 백업 로그는 D-072만 최종 상위5에 나오고 D-109·D-110은 문서 순위에서 밀린다. 날짜는 B 방식의 선호 조건이다. 현재100%는 새30에 한정된다.
3. 계약 유효기간과 문서일자 구분: Q-008의 2025년 계약 문서일자는 2024-12-22다. 기간 역할을 일괄 문서일자로 보면 안 된다.
4. 조건부 Qwen 질의 분석은 이번99개 중19번 호출을 시도했지만 모두 시간 초과 뒤 규칙으로 처리됐다. LLM 분석 성공과 검색 성공을 구분한다.
5. 원래 필터 정답과 추출 표현 차이 검수, 독립 자료·순위 품질·운영 성능 확인. 새30은 개선에 사용한 개발 질문 재평가다.

날짜 기준은 운영KST 오늘/평가2026-10-14이며 작성일·표지일·수정일은 분리한다. 새 계절 정책은 명시 연도만 우선하고 월은 확정하지 않는다. [상세 설계](docs/SEARCH_DESIGN.md). 모델 리랭커는 추가하지 않았다.

## 이후 실제 서비스 연결

- 실제 SharePoint/Graph 수집, 변경분·삭제 동기화, 원본 URL, 사용자별 접근 권한.
- 실제 운영 자료와 독립 검수 정답, 동시 요청·장애 복구 시험.

현재 API는 Orin `127.0.0.1:8020`, Mac 확인 화면은 인증된 SSH 터널을 통한 `127.0.0.1:18020`이다. VPN·SSH 연결이 끊기면 화면에 접근할 수 없다. 외부 공개 서비스가 아니다. 사용자 검색·클릭·피드백 기록은 저장하지 않는다.
