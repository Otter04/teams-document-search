# 기존 결과를 재사용한 110문서 BM25 인덱싱 완료

2026-10-20. **선택한 범위인 공통 블록 → 규칙 메타데이터 보강 → 청킹 → BM25 색인을 110/110문서에 대해 완료했다.** 새 모델 호출·임베딩 생성·검색 질의·답변 생성은 하지 않았다. 결과는 현재 Mac의 이 폴더에 저장되어 있으며 Orin으로 배포한 결과가 아니다.

BM25는 단어를 이용하는 색인·점수 계산 방식이며 임베딩 모델이 아니다. 이번 선택은 BM25까지이므로 벡터 생성은 이번 작업의 미완료 항목으로 집계하지 않는다. 검색 조건·정렬·결과 표시·답변 방식은 별도 설계 대상이다. 과거 개발용 검색 평가 코드는 보존했지만 이번 작업에서 검색·답변 서비스를 구현하거나 실행하지 않았다.

네이티브 텍스트가 있던 문서는 107개이고 스캔 전용 문서는 D-044·D-069·D-102의 3개다. 비전 대상 30개는 네이티브 문서 중 27개와 스캔 전용 3개로 구성된다. 따라서 107개와 30개를 더하면 중복 집계가 된다.

**110개를 Orin 모델로 새로 추론한 것이 아니다.** 기존 비교 실행기의 비전 25장·보강 20문서, 합계 45응답은 별도 보존한 중단 기록이며 현재 인덱싱 완료율의 분모·분자가 아니다. 이번 색인은 사용자가 승인한 기존 OpenRouter 결과 재사용 방침에 따른 것이다.

## 이번 마무리에서 바뀐 것

- 네이티브와 비전이 같은 위치에서 중복 추출한 문구 244개는 하나의 원문 블록을 참조하도록 정리했다. 같은 말이어도 다른 페이지·위치에 있으면 유지했다.
- 셀의 행·열·병합 구조와 내용이 같은 중복 표 25개는 기존 표에 연결했다. 원본 공통 블록은 별도 보존했다.
- 검수된 구성도 라벨·연결선 248개를 위치 근거가 있는 텍스트 블록으로 전달했다. 모델의 자유 설명 문장은 이 과정에 포함하지 않았다.
- 준비본의 1,156청크가 1,072청크로 정리됐다. 숫자 감소는 중복 통합·재청킹 결과이며 84개의 서로 다른 원문 내용을 버렸다는 뜻이 아니다.
- 중복 정리 전후 모든 메타데이터 값과 상태가 동일함을 확인했다.

스캔에서 새로 연결된 19개 값은 D-044의 계약번호·금액·기간 등 8개, D-069의 날짜·시스템·사이트 3개, D-102의 계약번호·금액·기간 등 8개다. 자세한 근거는 [변경 목록](metadata-changes.json)에 있다. 변경 목록에는 값의 신규 추출 외에 `pending_vision`에서 `not_found_text`로 바뀐 상태 변경도 포함되며 이를 새 정보 추출로 세지 않는다.

## 남겨둔 항목과 한계

1. **문서일자 모호성 13건:** D-005, D-015, D-023, D-033, D-043, D-047, D-057, D-067, D-079, D-089, D-096, D-101, D-107. 값은 `null`, 상태는 `needs_review`다. 해당 문서 본문은 색인됐지만 불확실한 날짜를 확정 필터값으로 쓰지 않는다. 파일 최종 수정시각·표지 날짜·명시적 작성일은 [날짜 메타데이터](date-metadata.jsonl)에서 각각 관리한다.
2. **이미지 설명 103문장:** 원문에 직접 적힌 글자·표·검수된 연결 관계와 별개인 모델의 설명이다. [검수 대기 목록](../vision-reuse-review-001/semantic-review-pending.json)에 보존하고 사실 색인에서 제외했다. 해당 문장의 일부가 원문 글자와 우연히 같더라도 검수되지 않은 `claims` 필드를 색인 입력으로 사용하지 않는다.
3. **필요한 문서의 요약:** 아직 선정·생성하지 않았다. 이번 메타데이터 우선 인덱싱의 필수 통과 조건이 아니다. 향후 표시·검색 요구가 정해질 때 대상과 기준을 정한다.

이 항목들은 현재 선택한 범위의 색인을 막지 않지만 모든 의미 정보가 완전하게 검수됐다는 뜻도 아니다. `not_found_text` 290필드는 현재 근거에서 찾지 못한 값이며 모두 모델 실패나 추가 호출 대상으로 간주하지 않는다. `not_applicable` 1,072필드는 해당 문서 종류에 적용하지 않는 필드다.

비전 121장은 기존 67장 그대로 채택, 규칙 교정 49장, 원본 대조 교정 4장, 직접 복원 1장으로 구성된다. D-102 2쪽은 모델 응답이 잘려 원본 이미지에서 일부를 복원했다. 따라서 121장 재사용 가능을 모델 정확도 100%나 독립 사람 검수 완료로 해석하지 않는다. 현재 선택한 원문·표·구조 범위에서는 필수 재호출 대상으로 남겨둔 장수가 0장이다.

## 검증과 파일 안내

[생성 검증](verification.json)과 [저장 결과 재검증](reload-verification.json)이 통과했다. 110개 실제 원본 파일의 해시, 공통 블록·메타데이터 형식, 청크 원문 참조·범위, 문서 누락 여부, 저장된 모든 단어 빈도를 확인했다. 검색 질문을 실행하지 않았으므로 검색 정확도 성적으로 제시하지 않는다.
