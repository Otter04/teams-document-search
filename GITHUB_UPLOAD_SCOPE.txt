The repository contains development code, design documents, local datasets,
and evaluation outputs, subject to .gitignore.

A complete workspace archive is published as a GitHub Release attachment:
teams-document-search-full-2026-10-27.zip
It additionally includes work/, temporary dependencies, caches, generated
large indexes and original ZIP/TAR bundles that are not tracked in Git.

and a list of exclusions. SHA256SUMS.txt verifies the archive itself.

Excluded from both the repository and the full archive:
- credentials and private-key/environment files;
- .git internal metadata (the repository itself preserves Git history).
Symbolic links are preserved as links. External linked folders, external
original datasets, Orin model weights and Elasticsearch volumes are not
copied into the archive because they are outside this workspace.

Local original files are preserved. Historical reports do not imply that
reported services are currently running. Full backup restores the archived
workspace files; credentials must be supplied separately.
